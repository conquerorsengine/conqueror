# template: basic3d
# 253: Occlusion Culling penceresi Unity gibi Object / Bake / Visualization sekmeli; Object sekmesindeki Occluder Static / Occludee
# Static pişirmeye uyar. Duvar (Occluder) arkasındaki küp gizlenir; duvar Occluder değilse gizlenmez; küp Occludee değilse hiç
# gizlenmez; yalnız Occludee olan (engel olmayan) ince levha, arkasındaki küpü gizlemez ama kendisi duvarın arkasında gizlenir.
# Göz noktası duvarın önünde (0 1 3, pişirilen hücrelerin içinde), bakılan her şey -Z yönünde.
wait 40
create_primitive Cube Wall 0 1 0
comp set Wall TransformComponent Scale 12 6 0.5
create_primitive Cube Box 0 1 -6
create_primitive Cube Sheet 0 1 -3
comp set Sheet TransformComponent Scale 12 6 0.1
create_primitive Cube Front 0 1 2
occlusion flags Wall 1 1
occlusion flags Box 1 1
occlusion flags Sheet 1 1
occlusion flags Front 1 1
occlusion bake 2
occlusion expect_hidden Front false 0 1 3
occlusion expect_hidden Box true 0 1 3
occlusion expect_hidden Sheet true 0 1 3
# Duvar engel değil: levha (hâlâ engel) kutuyu gizler, levha görünür
occlusion flags Wall 0 1
occlusion bake 2
occlusion expect_hidden Sheet false 0 1 3
occlusion expect_hidden Box true 0 1 3
# Levha da engel değil (yalnız Occludee): kutu görünür, levha görünür
occlusion flags Sheet 0 1
occlusion bake 2
occlusion expect_hidden Box false 0 1 3
occlusion expect_hidden Sheet false 0 1 3
# Duvar yeniden engel: ikisi de duvarın arkasında gizlenir (engel olmayan levha da gizlenebilir)
occlusion flags Wall 1 1
occlusion bake 2
occlusion expect_hidden Sheet true 0 1 3
occlusion expect_hidden Box true 0 1 3
# Kutu Occludee değil: duvarın arkasında da hiç gizlenmez
occlusion flags Box 1 0
occlusion bake 2
occlusion expect_hidden Box false 0 1 3
quit
