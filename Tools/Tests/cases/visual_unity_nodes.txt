# Formula
vsx node start event.start
vsx node f1 math.formula
vsx prop f1 Formula a\s*\s2\s+\sb
vsx default f1 a 3
vsx default f1 b 4
vsx node setF1 var.set
vsx prop setF1 Variable F1
vsx link start Then setF1 In
vsx link f1 Result setF1 Value
vsx node f2 math.formula
vsx prop f2 Formula a\s+\sBonus
vsx prop f2 Inputs 1
vsx default f2 a 1
vsx node setF2 var.set
vsx prop setF2 Variable F2
vsx link setF1 Then setF2 In
vsx link f2 Result setF2 Value
vsx node seq flow.sequence
vsx link setF2 Then seq In
