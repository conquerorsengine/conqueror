# 274: View > Screen UI in Scene açıkken tuvalin tamamını kaplayan yarı saydam karartma (Parkour menüsündeki %35'lik MenuRoot) sahne
# derinliğine tuvalin düzlemini yazıyordu; TAA arkadaki binaları bu derinlikle geri izlediği için kamera dönerken onlar parçalanıp
# bulaşıyordu. Yalnız çoğunlukla opak UI pikselleri derinlik yazar: karartmanın arkasındaki küpün derinliği UI kapalıykenkiyle aynı
# kalmalı, opak düğmenin olduğu yerde ise tuval derinliği yazılmalı (gizmo / sonra çizilenler için)
wait 30
create_primitive Cube Far 0 20 -60
entity scale Far 80 80 4
uieditor new_canvas HUD
uieditor add Image 960 540
entity rename Image Dim
comp set Dim RectTransformComponent SizeDelta 1920 1080
comp set Dim UIImageComponent Color 0 0 0 0.35
uieditor add Image 960 300
entity rename Image Solid
comp set Solid RectTransformComponent SizeDelta 300 200
comp set Solid UIImageComponent Color 0.1 0.1 0.2 0.95
comp set HUD TransformComponent Position 0 20 0
comp set HUD TransformComponent Rotation 0 0 0
focus Viewport
wait 5
camera 120 0 0 0 20 0
wait 20
view_option screen_ui off
wait 20
viewport_depth 0.5 0.6 mark
screenshot {work}/screen_ui_depth_off.png
view_option screen_ui on
wait 20
screenshot {work}/screen_ui_depth_on.png
viewport_depth 0.5 0.6 expect_same 0.00005
view_option screen_ui off
wait 20
viewport_depth 0.5 0.27 mark
view_option screen_ui on
wait 20
viewport_depth 0.5 0.27 expect_diff 0.00005
quit
