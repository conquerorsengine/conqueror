# Conqueror Core package

Built-in, read-only assets that every project can use without copying them into `Assets` (like Unity's built-in
packages): the default materials, the 2D shape sprites and the prototype grid texture. New 3D objects use
`Materials/Default Grid.cqmat`. To change a built-in material, use **New** in the Mesh Renderer's Materials section to
make an editable copy in your project.
