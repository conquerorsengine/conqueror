# Getting started

## Building the engine

Requirements: CMake 3.20+, a C++23 compiler (GCC 13+, Clang 17+ or MSVC 2022), Python 3 (optional, for the Python
scripting runtime). All other libraries are in `External/` and built from source.

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

The build produces three programs in `build/bin`:

| Program | Purpose |
|---------|---------|
| `ConquerorLauncher` | Project hub: create / open projects, templates, samples, learning material, modules |
| `ConquerorEngine` | The editor (`ConquerorEngine <project folder>` opens a project directly) |
| `ConquerorRuntime` | The player used by built games |

Platform-specific notes (Windows, macOS, FreeBSD, Android, QNX cross builds) are in the main [README](../README.md) and in
[Platforms](Platforms.md).

## Creating a project

Start `ConquerorLauncher`, choose **New Project**, pick an industry on the left (Games, Film / Video & Live Events,
Architecture, Automotive, Simulation), then a template and a folder:

| Template | Industry | What you get |
|----------|----------|--------------|
| 3D Core | Games | Empty 3D scene: main camera and a directional light, physical sky |
| 2D Core | Games | Orthographic 2D scene (sprites, tilemaps, 2D lights, Box2D physics) |
| 2D Platformer | Games | Side-scroller: tilemap level with pits and platforms, responsive jumping, 16 coins, goal flag |
| First Person | Games | First-person arms with a pistol and a marksman rifle on a shooting range: aim, recoil, reload, pop-up targets |
| Arena Shooter | Games | Free-for-all deathmatch against AI bots on a NavMesh arena: kill feed, leader, first to 15 kills |
| Third Person Shooter | Games | Over-the-shoulder mannequin with aiming and firing, free-for-all AI bots |
| Laser Tag | Games | Blue versus red teams with AI team mates, glowing taggers, team score |
| 3D Board Game | Games | Procedural hex island, a knight walking A* paths with preview, RTS camera, day / night cycle |
| Empty | Games | A camera and a light |
| Third Person | Games | Animated mannequin (idle / walk / sprint / jump) with an orbit camera in a test arena |
| Top Down | Games | Click or hold to walk along NavMesh paths (or WASD), cursor ring, zoomable follow camera |
| Vehicle | Games | Concept sports car: 3-lap time trial on an editable spline race track, off-road valley, autopilot |
| Virtual Reality | Games | XR Origin with two controllers: teleport arc, snap turn, grab and throw, a pistol and pop-up targets; XR Device Simulator without a headset |
| Augmented Reality | Games | Handheld AR furniture placement: plane detection with feature points, tap to place, move, resize, rotate; AR Simulation room without a camera |
| Feature Test | Games | Eighteen stations running the engine's systems side by side (physics, joints, IK, cloth, particles, render targets, CSG ...) |
| Virtual Production | Film / Video & Live Events | LED volume stage (270 degree wall), two actors and a concept car, a seven shot short film with dialogue, subtitles and focus pulls |
| Archviz Interior | Architecture | Furnished apartment with a garden view, sun through the windows, GI and reflections, day / evening lighting, walkthrough |
| Car Configurator | Automotive | Photo studio with a concept car on a turntable: paint, interior and wheel options, camera presets, cockpit view |
| Crowd Simulation | Simulation | Living city plaza: pedestrians wander, window-shop, sit, chat and come and go; follow camera, live crowd size |

The assets used by the templates are CC0: Poly Haven models, textures and skies, ambientCG textures, Kenney kits and
models, textures and sounds generated by the scripts in `Tools/Templates`. Each template's `Assets/LICENSE.txt` lists
its sources. Shared packages (`Resources/Templates/Shared`: Prototype grid textures, Mannequin, Weapons, Vehicles,
Furniture) are copied into the projects that use them.

Three complete games made with the engine, Tetris, Parkour and Ember Trail (2D platformer), are in the `Samples/` folder: open their `.cqproj` in the editor (or add the folder in the launcher) and press Play.

## Project layout

```
MyGame/
  MyGame.cqproj        project file (name, start scene, player settings, quality, input ...)
  Assets/              everything you import or create: Scenes/, Scripts/, Textures/, Models/, Audio/, Prefabs/ ...
  Config/              ConsoleVariables.ini (applied on load) and other text configuration
  ProjectSettings/     editor-managed settings (tags, layers, physics, build list)
  Packages/            installed add-ons
  Library/             caches (shader cache, imported asset data) — safe to delete, not under version control
```

Paths inside scenes are stored relative to the project, so a project folder can be moved or copied freely.

## Your first scene

1. **Create > Shape > Cube** (or right-click in the Hierarchy) adds an entity with a mesh. Move it with **W**, rotate with
   **E**, scale with **R**.
2. In the **Inspector**, **Add Component > Physics > Rigidbody** and **Box Collider** make it fall.
3. **Create > Script** in the Content Browser creates a script in the language of your choice (see [Scripting](Scripting.md));
   drag it onto the entity.
4. Press **Play** (top ribbon). The Game panel shows the primary camera. Press **Stop** to return; changes made during play
   are discarded, like in Unity.
5. **File > Save** (Ctrl+S) saves the scene.

## Building a game

**Build > Build Settings** (Ctrl+Shift+B): add scenes to the build list, choose the target platform, press **Build**. The
output folder contains the player executable, the project data and the engine library. See [Platforms](Platforms.md).
